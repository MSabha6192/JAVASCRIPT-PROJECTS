# JAVASCRIPT-PROJECTS
Projects

Pizza Menu

-Pizza ordering was created using various toppings and sizes. After a series of selections and clicking on place order, it generates the total amount spent and tells us what we ordered 

Tic-Tac-Toe Game

-A 3x3 grid was created in the classic game. When a player placed a piece, the CPU placed a piece as well. The game continues until there is a winner of when it is a draw and announces the result.

Calculator

-A basic operation calculator was created. It has function to perform various calculations. The calculator can reset to start a new operation all over again
